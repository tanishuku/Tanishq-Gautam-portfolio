# Tanishq Gautam — Developer Portfolio

A responsive, dark-themed personal portfolio with lime accents, glass-style navigation, animated details, project cards, skills, journey timeline, and contact section.

## Files

- `index.html` — the complete website (HTML, CSS, and JavaScript).
- `assets/favicon.png` — browser tab icon.
- `assets/background-1.jpg`, `background-2.jpg`, `background-3.jpg` — visual assets reused from the supplied files.
- `assets/banner.jpg` — social sharing image metadata asset.
- `package.json` — optional local preview scripts.
- `tsconfig.json` — optional TypeScript configuration if you later add TypeScript source files.

## Run locally

You can open `index.html` directly in a browser. For a local server with Node.js installed, run:

```bash
npm run start
```

If `serve` is not installed, `npx` may ask to download it. You can also use VS Code's Live Server extension.

## Before publishing

1. Replace the generic GitHub links (`https://github.com/`) with your profile and actual repository URLs.
2. Replace the generic LinkedIn link with your personal profile URL.
3. Add your real email address and wire the contact button to it (for example, a `mailto:` link).
4. Replace starter project descriptions with projects you have actually completed; don't claim skills you can't demonstrate.
5. Update the social preview URL if you deploy the site to a custom domain.

No framework or build step is required; the site is plain HTML, CSS, and JavaScript.
